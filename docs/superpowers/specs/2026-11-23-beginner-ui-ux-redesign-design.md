## 0. 一句话目标

让一个刚开户、看不懂“夏普/回撤/信号强度”的人，打开产品 30 秒内知道**今天要不要动、为什么、最坏亏多少**；同时让熟练用户一键展开证据、数据和进阶指标，不被简化版挡住。

**不是**把界面做“少”，而是把**重点做得更重、次要信息退后、危险信息不被折叠掉**。

## 1. 设计立场

### 1.1 产品人格

- **研究台，不是交易终端。** 不做红绿闪烁、滚动行情、倒计时压迫感；不做“错过就没了”。
- **冷静、诚实、可核对。** 每个结论旁边有来源和时间；没有数据就说没有；不确定就说不确定。
- **编辑室气质。** 像一份每天更新的研究简报：有标题、有导语、有证据、有更正；不是仪表盘拼盘。
- **默认不操作。** 不操作是正常结果，不是失败；页面要敢于显示“今天没有值得做的事”。

### 1.2 三条硬原则

1. **先回答，再解释。** 首屏先给结论和下一步；证据、计算、原始数据逐层展开。
2. **风险不能藏。** 最大亏损、反证、数据缺失、延迟、样本不足，必须在首屏或一级展开内可见，不能只放“进阶”。
3. **一个屏幕一个主任务。** 今日看“要不要动”；决策卡看“这张卡该不该执行”；持仓看“风险在哪”；复盘看“做对了没有”。

### 1.3 新手与进阶的双轨

- **新手模式（默认开启，首次使用 14 天）：** 只显示结论、人话解释、风险金额、下一步；隐藏夏普、索提诺、Brier、HHI 等术语，收进“进阶指标”。
- **进阶模式：** 显示完整指标、原始快照、规则版本、计算口径；不改变数据，只改变披露深度。
- 切换入口在设置与页面右上角“显示更多/精简显示”；状态持久化。
- 任何模式下，**风险、反证、数据质量、免责声明**都不能被隐藏。

### 2.2 主要问题

**信息架构**

- 侧栏 8 个入口分 3 组（`lib/nav.ts`）：今日、自选、持仓、投研台、研究笔记、信号分析、研究助手、任务中心。新手不知道先看哪个。
- `/today`（收盘简报）与 `/desk`（投研台）职责重叠：都展示市场、行业、提醒、数据质量；但一个用 `CockpitShell`，一个用 `AppShell`，视觉与交互不一致。
- 移动端底栏固定“今日/投研台/自选/持仓/任务中心”，没有“研究/复盘/模拟盘”；模拟盘上线后会进一步拥挤。
- `/analysis` 是 7 个区块的进阶分析页（总览/图表/情绪/趋势/事件/回测/时间线），对新手是信息墙；不应与“今日”同级。
- `/analytics/value` 是内部价值验证报告，不属于日常主流程。

**首屏与信息层级**

- `/today` 首屏是“收盘判断”大卡 + 市场快照 + 证据脊柱 + 个人影响 + 文档 + 明日 + 数据质量，用户要滚很久才知道“今天要做什么”。
- `/desk` 同时有市场判断、行业、提醒、外盘、延迟行情；缺少“今天最重要的一件事”的收敛。
- `/portfolio` 有总市值/浮盈/集中度/风险/行业/持仓，但缺少“今天发生了什么变化”和“我现在该做什么”。
- `/research`、`/agent`、`/analysis` 各自完整，但彼此没有清晰的“从结论到证据到提问”的路径。

**新手可读性**

- 术语密度高：信号、论点、置信度、回撤、集中度、夏普、索提诺、Brier、换手、滑点、T+1、涨停/跌停。
- `Hint` 存在但覆盖不全；关键数字旁常没有“这意味着什么”。
- 置信度只有“高/中/低”或分数，没有解释“分数由什么构成、多少算够”。
- 风险提示常是结构描述（“前三大集中度 43%”），没有换算成“如果明天跌 5%，你会亏多少钱”。
- 空态有时只说明“没有数据”，没有说明“这是因为没运行、没入库，还是今天确实没有机会”。

**数据展示**

- 来源/时间/延迟常以小字放在卡片底部，首屏不够显性；新手容易把“昨天的收盘”当成“今天实时”。
- 表格在移动端依赖横向滚动；关键列（盈亏、风险）可能被滚出视野。
- 图表缺少统一的“表格视图/文字摘要”，颜色和图形承担了过多语义。
- 旧页面（`/analysis`）的图表体系与新驾驶舱（`ck-*`）不完全统一。

**响应式与可访问性**

- 移动端底栏 5 项已满；新增模拟盘需要重新分配，不是继续加。
- 部分辅助文字 11px，低于移动端舒适阅读；关键风险不能放在 11px。
- 需要系统检查：焦点可见性、弹层焦点回收、图表 aria、触控目标 ≥44px、`prefers-reduced-motion`、200% 缩放、320px 宽度。
- 颜色语义总体正确（红涨绿跌），但仍需保证“不靠颜色单独传达”。

## 3. 信息架构

### 3.1 新的主导航（5 项）

| 主导航 | 路由 | 一句话任务 | 合并/降级 |
|---|---|---|---|
| **今日** | `/today` | 今天要不要动 | 吸收 `/desk` 的盘中视图；`/desk` 保留为重定向/深链 |
| **模拟盘** | `/paper` | 今天有哪些卡、该不该执行 | 新增；含决策卡、委托、成交；`/decisions` 为短链别名 |
| **持仓** | `/portfolio` | 我的钱在哪、风险在哪 | 加入“模拟盘/真实记录”切换；纸面账本为主 |
| **复盘** | `/reviews` | 我做对了没有 | 新增；吸收日报/周报；`/analytics/value` 降为进阶 |
| **研究** | `/research` | 我为什么这么看 | 收纳自选、个股、行业/政策、新闻、助手、笔记 |

**为什么不是“今日 / 模拟交易 / 持仓 / 自选 / 研究”：** 审计建议把“自选”放进底栏、把研究收进更多。本规格选择把“复盘”放进底栏，因为模拟盘 MVP 的主闭环是“今日 → 模拟盘 → 持仓 → 复盘”；自选是研究输入，放在“研究”一级只多一次点击，不影响每天的主任务。

**系统入口（不占主导航）：**

- 任务中心 `/tasks`：放在顶栏“运行状态”菜单与设置里；失败时在今日页顶部提示。
- 数据健康 `/data`：放在顶栏状态胶囊、今日页“数据可信度”与设置里。
- 设置：头像菜单（现有 `AvatarMenu` + `SettingsDialog`）。
- 进阶工具：`/analysis`、`/analytics/value` 收进“研究 → 进阶工具”，不在一级导航。

## 4. 页面级规格

### 4.0 通用页面骨架

**桌面：**

```
┌ 顶栏：面包屑 · 数据状态胶囊 · 搜索/命令 · 头像 ┐
├ 侧栏 ┬──────────────────────────────┬ 上下文栏 ┤
│      │ 页面标题 + 一句话任务          │ 可选：     │
│      │ 主内容（单列，最大 720–840px）  │ 今日待办   │
│      │                                │ 数据状态   │
└──────┴──────────────────────────────┴──────────┘
```

**移动：**

```
┌ 顶栏：返回 · 页面名 · 状态 · 头像 ┐
│ 页面标题 + 一句话                  │
│ 主内容（单列）                     │
│ 粘性主操作条（仅详情/委托页）       │
└ 底栏：今日 模拟盘 持仓 复盘 研究 ──┘
```

- 主内容最大宽度 840px；数据表/图表可扩展到 1120px。
- 桌面上下文栏只在详情页使用，移动端折叠到底部“更多信息”。
- 页面标题下必须有一句“这个页面能帮你做什么”，不超过 30 字。

**主任务：** 今天要不要动。

```
[看这张卡]  [今天不操作]
```

- 账户条是模拟盘启用后的第一行：虚拟资产、盈亏、可用现金、冻结。盈亏必须按会话标注：盘前显示“昨日”，盘中显示“延迟估值”并标 `stale`，盘后显示“官方结算”。
- 没有模拟盘时退化为“今日市场 + 你的手动持仓”。
- “今天要做”只列**需要用户决策**的事项：待确认卡、待处理风险、数据修复。已自动完成的结算、对账只放在状态行，不伪装成待办。
- 自选异动不单独占一块，合并进“你的持仓/自选”卡片：最多 3 条，按影响排序。

**往下（按需展开）：**

1. **市场快照**：3 个指数 + 涨跌家数条 + 两市成交；来源与时间在行内；点击展开行业/新闻。
2. **你的持仓与自选**：最多 3 条“持仓/自选 + 今日相关事件/决策”，没有则显示“今天没有影响你持仓的新事件”。
3. **数据可信度**：3 个关键源状态；异常时给“检查数据”按钮；正常时折叠成一行。
4. **明日/下周**：最多 3 条日历事件；不堆新闻列表。

**会话切换：**

- 顶部分段控件：`盘前` / `盘中` / `盘后`；默认按当前时间选择。
- 盘前：昨日收盘 + 隔夜外盘 + 今日公告 + 已触发待确认卡 + 09:15 截止提醒。
- 盘中：延迟行情 + 风险提示 + 已确认委托状态；明确标注“延迟 N 分钟，不用于纸面成交；今天不会在盘中成交”。
- 盘后：官方开盘价结算结果 + 对账状态 + 复盘入口。
- 16:20 前的已确认委托统一显示“已确认，待收盘确认”，不显示“已成交”，也不显示预计成交价为新价格。
- 非交易日：整页显示“今天休市”，只保留“看看研究/设置提醒”，不生成空简报。

**空态：**

- 没有卡、没有持仓、数据正常：`今天没有需要你做的事。` 副文案：`这不是系统坏了；没有满足条件的决策卡，也没有触发的风险。` 操作：`看看观察名单` / `了解系统怎么判断`。
- 数据没跑：`今天的数据还没准备好。` 副文案说明是未运行/未入库/源异常，操作：`去任务中心运行`。
- 数据失败：`今天的行情没有更新，所以不生成决策。` 操作：`查看数据状态`，不显示昨日结论冒充今日。

**不要做：**

- 首屏不要放完整证据脊柱、完整新闻列表、全部行业图表。
- 不要用“今日必看/重大机会/错过”等煽动性标题。
- 不要在没有卡时放一个巨大的空白英雄区；空态要短、要给出下一步。

### 4.2 模拟盘 `/paper`

**主任务：** 看今天有哪些卡、哪张需要我决定；看纸面账户和委托状态。

**页内结构：**

- 顶部账户条：虚拟资产、昨日/今日盈亏、可用现金、冻结、数据时间；固定“虚拟资金”标识。
- 状态条：对账状态、待收盘确认数、kill switch/数据质量异常；异常时置顶，正常时折叠成一行。
- 分段：`决策卡`（默认）/ `委托` / `成交`；历史与观察折叠，不默认铺满。
- 决策卡列表即 `/paper/decisions`；委托/成交为 `/paper/orders`；详情为 `/paper/decisions/[id]`。

```
决策卡   [待触发 3] [已触发待确认 1] [已确认待收盘确认 0] [已成交] [已过期]
今天只有 1 张需要你决定；其余在等条件，不用操作。

┌ 招商银行 600036 · 候选 · 证据分 62/100 ────────────┐
│ 一句话：行业相对强弱回升，估值不贵，等回踩确认。   │
│ 已触发 · 计划买 1,000 股 · 最多亏约 ¥2,435         │
│ 09:15 截止   [查看理由]                  [再想想] │
└────────────────────────────────────────────────────┘

┌ 宁德时代 300750 · 观察 · 证据分 48/100 ────────────┐
│ 一句话：政策利好但价格未确认，先观察。              │
│ 等待触发 · 不需要操作                               │
└────────────────────────────────────────────────────┘
```

- 排序：已触发待确认 → 已确认待收盘确认 → 待触发 → 已成交/过期；同组按证据分降序。
- 每张卡首屏只给：名称/代码、立场、一句话、触发状态、最多买多少、最多亏多少、截止时间、主操作。
- 列表页只给“查看理由”和“再想想”；**不提供“纸面买入”**。执行必须进详情页，看过风险信封后确认。
- 状态文案统一为：`待触发` / `已触发待确认` / `已确认待收盘确认` / `已成交` / `未触发` / `已证伪` / `已过期` / `已忽略`；不用“处理中”“已拒绝”这种模糊或错位词。
- 立场徽章：图标 + 文案 + 颜色；不能只靠颜色。
- 证据分：数字 + 一句解释（“62/100：证据一般，建议再观察”），点击展开四项输入；不写“建议轻仓”，仓位由风控和止损决定。
- “再想想”会记录原因（再等等/风险太高/看不懂/不认同），用于复盘，不产生委托；卡片转 `已忽略`，5 秒内可撤销。
- 已确认委托显示“待收盘确认”，并提供“09:15 前可撤单”；截止后按钮禁用并说明“已过确认截止时间”。
- 观察卡提供“为什么出现这只”链接：抽屉显示来源（自选/行业候选/持仓风险）与入选原因，避免用户以为系统在荐股。
- 空态：`今天没有值得动的机会。` 副文案：`市场状态/数据质量/触发条件不满足，所以系统建议不动。` 操作：`看观察名单` / `了解判断规则`。
- 不要用无限滚动；MVP 每天最多 5 张卡。

### 4.3 决策卡详情 `/paper/decisions/[id]`

**主任务：** 决定这张卡要不要纸面执行。

**结构（五块，按顺序）：**

1. **结论**
   - 标的、立场、证据分、周期、一句话。
   - 状态：`待触发` / `已触发待确认` / `已确认待收盘确认` / `已成交` / `未触发` / `已证伪` / `已过期` / `已忽略`。
   - 主操作：`纸面买入`（仅候选、已触发、风控通过）；已确认后变为 `已确认，待收盘确认` + `09:15 前可撤单`；次操作：`再想想` / `不操作`。
   - 固定提示：`虚拟资金 · 不构成投资建议`。

2. **为什么**
   - 证据脊柱：3–5 条，事实/推断/反证/结论用文字标签 + 图标区分。
   - 每条证据有来源芯片和时间；没有来源的推断必须标“推断，无外部来源”。
   - 至少一条反证用不同底色/边框强调，不能藏在最后。

3. **什么时候动手**
   - 触发条件：价格/事件/日期 + 触发依据（收盘价/事件/开盘价）；显示当前距离（“还差 2.1%”）。
   - 未触发时：`现在不动；触发后不会自动下单，你会在下次打开时看到状态`。
   - 触发依据是“开盘价”时：`开盘价不高于 35.20 才成交；不满足就作废，不会事后提醒你再确认`。
   - 已触发时：`已满足条件，需要你在 09:15 前确认`。
   - 已确认时：`已确认，待 16:20 按官方开盘价结算；09:15 后不能撤单`。
   - 未触发：`条件没出现，卡已作废`；已过期：`截止前没确认，不再执行`；结算缺价：`没有官方开盘价，委托被拒绝`。

4. **风险**
   - 最大仓位（% 和金额）、**计划最大亏损**（¥ 和 %）、止损价、证伪条件。
   - 最大亏损旁固定写：`按止损价估算；跳空、停牌、退市可能更大`。
   - 对组合的影响：`买入后该行业占比 21.5% → 39.0%，接近 40% 上限`。
   - 流动性：`近 20 日日均成交 8.2 亿，按计划买入约占 0.3%`。
   - 一手可行性：`一手约 3,520 元，低于单票上限 40,000 元`；买不起一手时只给观察，不显示买入按钮。
   - 数据质量：`行情正常 / 公告延迟 12 分钟`。
   - 任何风控拦截：具体规则 + 实际值 + 新手文案 + `怎么办`。

5. **复核**
   - 复核日、要检查什么、历史卡与结果。
   - `到期后系统会提醒你复核；不会自动续期/自动加仓`。
   - 买入后持续监控证伪条件；触发证伪会生成退出卡，不依赖下一次行业筛选。

**纸面委托票（底部抽屉/移动端粘性条）：**

```
纸面买入 · 招商银行 600036
股数        1,000 股
参考价      35.20 元（以目标交易日官方开盘价 ± 滑点为结算依据）
预计金额    35,200 元
费用        约 9 元（佣金 + 过户费）
最多亏      约 2,435 元（组合 1.2%；含买卖费用，按止损价 32.80 估算）
止损/证伪   32.80 止损 / 31.50 证伪（均按收盘价）
结算        目标交易日 16:20 按官方开盘价结算；09:15 前可撤单

[确认纸面买入 1,000 股]   [取消]
```

- 按钮写“确认纸面买入 1,000 股”，不写“提交”。
- 确认前必须让用户看到“最多亏多少”和“按什么价结算”；不能只写百分比。
- 确认后显示 `已确认，待收盘确认（16:20 结算）`，并提供 09:15 前撤单；成交/拒绝在 `/paper/orders` 与今日页显示。
- 若开盘价使实际最大亏损超过单笔上限，结算时按 `RISK_GAP` 拒绝；票上必须提前说明。
- 不用连续弹窗；最多“详情页 → 票 → 结果”三层。

**“用大白话解释”**：可选按钮，调用 LLM 把证据归纳成 3 句话；必须标注“AI 解释，数字以证据为准”，且不能替代证据。默认不展开，避免新手只看叙述。

**进阶抽屉：**

- 原始快照、数据源清单、规则版本、计算明细。
- 默认折叠；不要求新手理解；但必须可追溯。

### 4.4 持仓 `/portfolio`

**主任务：** 我的钱在哪、风险在哪。

**顶部切换：**

```
[模拟盘（虚拟资金）] [真实记录（手动）]
```

- 默认进入“模拟盘”；真实记录明确标注“手动录入，不是券商同步”。
- 两个 tab 的数据绝不混算；顶部固定说明。
- 模拟盘首次进入：`还没有纸面持仓` + `去看今天的决策卡` / `先模拟一笔`。

**首屏：**

```
模拟盘 · 虚拟资金 ¥200,000
总资产 ¥201,240   今日 +¥240 (+0.12%)   累计 vs 沪深300全收益 +0.8%
[风险状态：正常] [对账：通过] [数据截至 15:05]
[待收盘确认 1 笔 · 冻结 ¥35,200]

今天的变化
· 1 笔已确认，待 16:20 结算
· 招商银行分红 ¥120（税前，卖出时按持有期扣税）
· 组合回撤 2.1%，未触发暂停线

持仓（3）   [按风险排序]
...
```

- 指标最多 4 个；默认显示“总资产、今日、累计超额、最大回撤”。
- “累计超额”旁有 `?`：`扣费后相对沪深300全收益；样本 23 天，不足 120 天时只显示计数，不显示百分比结论`。
- 基准名称写全：`沪深300全收益`；只有价格指数时标 `估算全收益（含股息率）`，不把股息算成 alpha。
- 风险状态用一句话 + 颜色 + 图标；不要只给一个红色圆点。
- 对账状态显示“通过/失败”；失败可点开四条恒等式与差异项。
- 待收盘确认的委托不显示为成交；成交后才更新持仓与市值。
- “今天的变化”最多 3 条；没有变化就写“今天没有交易，也没有触发风险”。

**持仓：**

- 移动端卡片：名称/代码、总持仓/可用/冻结、现价/成本、市值/权重、盈亏、风险标记；点开看详情。
- 桌面表格：标的、总持仓/可用/冻结、成本/现价、市值/权重、盈亏、风险；数字右对齐、等宽数字。
- 默认按风险排序（权重 × 波动/风险标记），不是按盈亏；新手先看风险。
- “总持仓 / 可用 / 冻结”三者分开显示；T+1 用一句人话解释（`今天买的明天才能卖`）；冻结写明对应哪笔待结算委托。
- 缺失价格：显示 `—` + `缺价，未计入市值`；不能按 0。
- 首屏必须显示覆盖与分母：`价格覆盖 8/10 只 · 2 只缺价未计入市值 ¥12,400 · 总资产和收益率分母不含缺价持仓`。不能只在页脚小字说明。
- 每个价格块统一 `截至 HH:MM · 来源`；持仓页不能只给“最新收盘价”而不给日期。
- 每行提供“纸面减仓”（仅 `可用 > 0` 且非跌停/停牌）：必须填原因，标记 `off_plan`，执行后进入复盘；不提供“一键清仓”。
- 持有后变 ST/停牌/退市：行内显示风险标记，只保留“减仓/退出”，不显示“加仓”；数据不可用时只能标注，不能假装已卖出。

**风险面板：**

- 单票、行业、集中度、现金、回撤、流动性、对账；每条给“当前值 / 上限 / 影响”。
- 示例：`白酒行业 43%，超过 40% 上限；再买这只酒股会被拦截。`
- 只有规则被触发时才用警告色；正常项保持中性，避免“满屏红”。
- 对账失败显示 `账本不平，已暂停新委托`；kill switch 显示触发原因与“最早下一交易日可申请解除”，不显示“立即恢复”按钮。
- 提供 `这些规则怎么来的` 抽屉，解释参数与可调整范围（MVP 只读）。

**不要做：**

- 不把“今日盈亏”放在最大字号；总资产/风险更重要。
- 不在首屏堆行业饼图、历史净值、全部指标。
- 不允许在持仓页直接改纸面持仓数量；减仓必须走带原因的纸面减仓（`off_plan`），不能直接编辑股数或成本。
- 不把待收盘确认的委托计入持仓或成交。

### 4.5 复盘 `/reviews`

**主任务：** 我做对了没有，下一次怎么改。

**首屏：**

```
复盘 · 本周（11/17–11/21）
事实摘要：
1. 触发 2 张卡，确认 1 张，成交 1 张；漏执行 1 张（原因：没在 09:15 前确认）。
2. 实际组合 +¥800，影子组合 +¥1,100；执行 1/2。
3. 对账 5/5 天通过；无风控违规；1 天缺价，已标注。

[系统判断·影子] [我的执行·纸面] [执行率]
+¥1,100          +¥800            1/2

本周 5 个交易日 / 2 张触发卡；不足 120 天，只列事实，不做有效性结论
```

- “事实摘要”是结构化总结（可 LLM 叙述，但必须引用事实）；没有足够数据时写“本周没有足够样本，只列事实”。
- 双轨固定三栏：影子组合、实际组合、执行率与偏离原因；两条结果不得合并成一条曲线。
- 偏离原因分 `没确认` / `风控拦截` / `数据缺失` / `计划外操作` / `延迟执行`；执行率低于 80% 时先解释原因，不先谈收益。
- 指标卡只在样本达标后显示收益率/胜率/夏普等百分比结论；样本不足时只显示计数、金额和天数。
- 默认隐藏夏普/索提诺/Brier/HHI；点“进阶指标”展开。
- 图表：一条实际净值 + 一条影子净值 + 一条回撤曲线；单轴、有图例、可切换表格；影子/实际用分类色，不用红绿。
- 决策质量：`判断对/执行对` 四象限，用数量 + 例子，不用复杂散点。
- 行为复盘：违规、追涨、忽略证伪、超仓、`off_plan`；没有则明确写“本周没有违规”。
- 对账：显示每日通过/失败与差异项；失败日必须解释，不能只写“暂无数据”。
- 时间线：每日一条，点击展开成交/风险/复盘。
- 日志：`今天学到了什么` 可选输入，保存到现有 `journal_entries`。
- 空态：`还没有复盘；收盘后自动生成，或手动运行一次。`

### 4.6 研究 `/research`

**主任务：** 我为什么这么看；把一个结论追到证据。

`/research` 是研究 hub，`?tab=` 同步当前分区；默认进入“自选”。原 `/research` 的笔记内容迁移到 `/research/notes`，旧深链不 404。

**子导航（分段/侧栏二级）：**

```
自选 | 个股档案 | 行业与政策 | 新闻线索 | 研究助手 | 笔记与档案 | 进阶工具
```

- **自选**（`?tab=watchlist`，默认）：沿用 `/watchlist` 的列表；每行给价格、论点状态、下一事件；点击展开证据或进个股。
- **个股档案**（`/stock/[code]`）：顶部报价 + 论点 + 证据 + 公告 + 历史决策卡；操作：`加入自选`、`申请纳入候选池`。决策卡只能由系统按规则生成，用户不能手动强造。
- **行业与政策**（`?tab=industry`）：把 `/analysis` 的行业/政策结论提炼成“结论 + 证据 + 相关个股”，图表放二级；不要默认展示 7 个区块。
- **新闻线索**（`/` 或 `/research?tab=news`）：沿用新闻流；每条给来源、时间、影响行业/个股；可“加入研究”。
- **研究助手**（`/agent`）：支持从决策卡/个股页带上下文进入；空态给 3 个示例问题；明确“助手不直接下单”。
- **笔记与档案**（`/research/notes`）：沿用原 `/research` 的论点/日志；高级编辑表单放抽屉。
- **进阶工具**（`?tab=advanced`）：`/analysis` 完整图表、回测、`/analytics/value`；默认折叠，标注“进阶/内部验证”。

**研究页原则：**

- 研究是“为什么”的家，不是第二个“今日”；不要把市场快照/待办再抄一遍。
- 候选池只解释“为什么出现这只”（自选/行业候选/持仓风险），不暗示推荐；观察卡不等于买入建议。
- 任何结论都能一键跳到“相关证据/公告/决策卡”。
- 长文用 36–40 字/行；段落之间留白；不用满屏卡片。
- 研究日志只写“记录观点 / 记录复盘”，不出现“记录买入/卖出”；纸面交易只能从决策卡发起，避免被误认为真实交易。

### 4.7 数据健康 `/data`

**主任务：** 现在哪些数据能信、哪些不能。

```
数据状态：部分延迟
[行情] 正常 · 16:10 入库
[公告] 延迟 12 分钟 · 影响：明日决策卡 1 张标注警告
[新闻] 正常 · 5 分钟前
[宏观] 未接入 · 不影响今日决策
[对账] 通过 · 四条恒等式 0 差异
[备份] 今日 16:35 成功 · 最近恢复演练 11/15 通过

受影响的功能：纸面结算正常（16:20）；决策卡可看但需确认警告。
[重新检查] [查看运行记录]
```

- 首屏先给“能不能交易/能不能看”的结论，再给源列表。
- 每个源：状态、最后更新、延迟、影响范围、修复动作。
- 缺价单独列 `MISSING_PRICE`：只停该标的新买入，不停整个账户；账本不平才是 `LEDGER_MISMATCH`，会触发 kill switch。
- 备份与恢复演练单独一块：最近成功时间、校验结果、上次演练；失败时给“立即备份/查看日志”。
- 原始日志/堆栈放抽屉；新手默认看不到。
- 示例数据：顶部水印 + `切到真实数据` 说明；不允许悄悄混用。

### 4.8 任务中心 `/tasks`

- 首屏：`运行中` / `最近完成` / `失败`；下一次自动运行时间。
- 每个任务：名称、状态、开始时间、耗时、结果一句话；失败给“为什么/重试”。
- 手动运行按钮只给安全任务；写操作任务需确认。
- 日志/事件流放抽屉；默认不展示 JSON。

### 4.9 设置

设置分两段，默认只显示“基础”；“高级”折叠，展开后仍需二次点击进入。

**基础（默认可见）**

1. **显示**：新手/进阶模式、浅色/深色/跟随系统。
2. **通知**：待确认卡截止、风险、数据失败、结算完成；默认只开关键项。
3. **模拟盘**：初始资金、实验周期、有效交易日、暂停/结束状态（只读摘要）；开始/暂停入口放高级并二次确认。
4. **关于**：版本、免责声明、数据许可、隐私。

**高级（默认折叠）**

5. **风控参数**：MVP 只读；展示当前阈值与“为什么这样设”。
6. **数据源**：状态、凭据（不显示明文）、刷新频率；沿用现有设置弹窗。
7. **实验管理**：开始新实验（锁定协议）、暂停（写原因）、重置（导出备份 + 关闭旧账户只读 + 新开 `-v2` + 重新计时 + 显示重置次数）。
8. **备份与恢复**：立即备份、查看最近备份、恢复演练、导出数据。
9. **实验维护**：数据导出、清理缓存。

- 每项给一句人话说明，变量名/JSON/内部枚举不直接出现在基础层。
- 实验开始后不能改规则、基准、费用假设或阈值；改了视为新实验，不能在同一实验里移动球门。
- 重置不清空历史：旧账户只读保留，新账户另起；重置次数必须显示。
- 设置不出现“接入券商/真实下单”；未来 L3 才加，且单独高风险确认。

### 4.10 匿名分享页 `/agent/s/[token]`

**主任务：** 打开别人分享的研究记录，不登录也能读。

```
[品牌]                                    [打开自己的驾驶舱]
分享的研究 · 2026-11-23 · 7 天后过期
问题：…  回答摘要（已脱敏）：…
[来源标题 + 链接]
```

- 使用 bare layout：不渲染侧栏、底栏、头像菜单，不调用需要登录的会话接口。
- 不做 401 跳转；分享失效时给“这份分享已过期或撤回”，不引导登录。
- 只读：不能继续对话、不能看个人持仓/自选。
- **分享范围严格限定**：用户问题 + AI 摘要 + 来源标题/链接；禁止包含决策卡、纸面持仓/委托/成交/净值、个人笔记、原文大段摘录、原始行情数据。
- 默认 7 天过期、可随时撤回；生成时给脱敏预览；页面加 `noindex`，不进搜索/社交预览。
- 来源受限或付费时只显示标题，不复制正文；遵守数据许可，不转售、不公开原始行情。
- 移动端单列，正文最大 720px；来源链接 `rel="noopener noreferrer"`。

## 5. 视觉系统

### 5.1 方向

**“雾灰绿纸面 + 砚青墨色 + 朱砂/琥珀警示”**：像研究台的纸张、墨水和批注，不像交易终端。

- 背景是暖中性纸色，不是纯白；卡片用细边框和极轻阴影，不堆叠玻璃拟态。
- 主色是砚青（深青灰），用于导航、链接、主按钮；不要用蓝色作为默认“金融科技”色。
- 涨跌仍用 A 股红/绿：红涨、绿跌；品牌色不得占用红/绿语义。
- 红绿只表价格方向；成功用砚青 + 对勾，警示用琥珀 + 三角，危险用深朱 + 图标 + 文案。状态色保留，不与分类色混用。
- 深色模式不是简单反相：纸色变墨色，砚青变浅青，红绿提亮并重新验证对比度。

> 当前 `styles/globals.css` 的主色是蓝色（`#2563eb`），`styles/cockpit.css` 已放弃独立雾灰绿主题。本次重构建议恢复“雾灰绿 + 砚青”的已批准方向；实施前用对比度工具验证，不直接照搬旧稿。

### 5.2 候选 token（实施前验证）

| 语义 | 浅色候选 | 深色候选 | 用途 |
|---|---|---|---|
| `--paper` | `#F7F5F0` | `#121513` | 页面背景 |
| `--surface` | `#FFFFFF` | `#191D1A` | 卡片/弹层 |
| `--surface-2` | `#F1EEE7` | `#202622` | 次级块 |
| `--ink` | `#1F2421` | `#E8E6E0` | 正文 |
| `--muted` | `#6B716C` | `#A6ADA5` | 次要文字 |
| `--line` | `#E2DFD7` | `#2C332E` | 边框/分隔 |
| `--accent` | `#2F5D62` | `#7FB3B0` | 主色/链接/主按钮 |
| `--accent-soft` | `#E6EEEC` | `#1E3334` | 主色浅底 |
| `--up` | `#B23A32` | `#E06B5F` | 涨/正收益 |
| `--down` | `#2F7D5A` | `#62B58A` | 跌/负收益 |
| `--warn` | `#9A6A1F` | `#D6A84A` | 警告 |
| `--critical` | `#8C2323` | `#F2A6A0` | 拦截/失败文字与图标（必须配文案，不与涨跌同区） |
| `--focus` | `#2F5D62` | `#9BC7C3` | 焦点环 |

**规则：**

- 正文对比度 ≥ 4.5:1；大字/图标 ≥ 3:1；实施前逐对验证。
- **红/绿是价格方向专用**：只用于涨跌、盈亏、相对基准的超额。禁止用于成功/失败、信号强弱、情绪冷暖、行业分类、按钮状态。
- 成功/完成：`--accent` + 对勾，不用绿；警告：`--warn` + 三角；危险/拦截：`--critical` + 图标 + 文案，且同一区域不再混用涨跌红。
- 状态色必须带图标 + 文案；不能只靠颜色。
- **待收盘确认**：琥珀 + 沙漏图标 + “待收盘确认”；不是完成态，不用绿色/对勾。
- **影子 vs 实际**：用砚青/灰蓝分类色 + 实线/虚线区分，不用红绿；图例必须写全“系统判断（影子）/我的执行（纸面）”。
- **对账失败**：深朱 + 盾牌/叹号 + “账本不平”，与涨跌红分开区域，不能只给一个红点。
- 图表分类色固定顺序，不循环；顺序色单色深浅；发散色双极 + 中性灰。
- 情绪/信号强度这类非方向量：用蓝↔橙发散或单色顺序，不用红绿。
- 不使用双轴图；两个量纲拆两张图或指数化。

### 5.3 字体

- UI/正文：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`。
- 编辑性标题（今日一句话、报告标题）：可选 `"Songti SC", "Noto Serif SC", serif`；只用在大标题，不用于数据。
- 数字：`font-variant-numeric: tabular-nums`；金额、比例、代码全部等宽数字。
- 字号：正文 16px（移动端不小于 15px）；次要 13–14px；辅助 12px 下限；关键风险不小于 14px。
- 行高：正文 1.6；标题 1.25–1.35；中文行长 36–40 字。
- 不加载重型 Web Font；PWA/离线优先。

### 5.4 布局与形状

- 间距：4/8/12/16/24/32/48/64；页面左右 16（移动）/24（平板）/32（桌面）。
- 主内容最大 840px；数据页最大 1120px；桌面详情两栏：主栏 + 280px 上下文栏。
- 圆角：卡片 12px；按钮 8px；标签 6px；不使用全圆角药丸堆叠。
- 边框优先于阴影；阴影只用于浮层/抽屉。
- 分割线：1px `--line`；分组标题用小号大写字距，不用彩色横幅。
- 图标：Lucide 线性图标；统一 16/20/24；不使用 emoji 作为状态图标。

### 5.5 标志性元素

**“风险信封”**：每张决策卡右侧/底部有一条窄条，只写三件事：`最多买多少`、`最多亏多少`、`什么情况下认错`。它是全产品最有辨识度的组件，也是新手最需要的安全感。

- 桌面：卡片右侧 1/3；移动：卡片底部三行。
- 颜色只用中性 + 一条风险色边；不做仪表盘/指针。
- 所有数值可点击展开计算口径。

## 7. 数据展示规范

### 7.1 数字与单位

| 类型 | 规则 | 示例 |
|---|---|---|
| 金额 | `¥` + 千分位；大额用万/亿，tooltip 给精确值 | `¥201,240`、`12.4 亿` |
| 收益/涨跌 | 两位小数；带符号；红涨绿跌 + 箭头 | `+0.82%`、`-1.20%` |
| 权重/仓位 | 一位小数 | `38.4%` |
| 证据分 | 整数 0–100；附人话 | `62/100 · 证据一般` |
| 股数 | 千分位；区分总持仓/可用/冻结 | `1,200 股 · 可用 0 · 冻结 1,000` |
| 价格 | 两位小数；指数可两位 | `1,682.00` |
| 日期 | UI `11月23日 周一`；tooltip ISO | `2026-11-23` |
| 时间 | `15:05`；跨时区标 `北京时间` | `15:05` |
| 缺失 | `—` + 原因 tooltip；不写 0、不写“暂无数据”了事 | `—（缺价，未计入市值）` |

- 同一区块内只用一种单位；混用万/亿时在表头统一，不在每个格子里变。
- 百分比必须说明分母：收益率 = 盈亏 / 成本，权重 = 市值 / 已覆盖市值，组合收益 = 日盈亏 / 前一日净值。
- 最大亏损是估算：写 `约 ¥2,435`，并标 `按止损价估算；跳空/停牌/退市可能更大`；不能写“最多只亏这么多”。
- 样本不足 120 个有效交易日、30 张触发卡或 60 日观察窗未满时：只显示计数、金额、天数，不显示胜率/夏普/超额百分比结论。
- 覆盖与排除必须显性：`价格覆盖 8/10 只 · 2 只缺价未计入市值 ¥12,400`；不能只算“能算的那部分”而不说。
- 桌面表格支持按列排序（市值、盈亏、权重），表头给 `aria-sort`；提供“只看有持仓/只看亏损/只看缺价”筛选。移动端卡片不改排序语义。
- 数字列右对齐、等宽数字；正负号与颜色同时出现；单位在表头，不在每行重复。

### 7.2 时间、来源、延迟

- 每个数据块必须有 `截至 HH:MM · 来源`；不能只在页脚。
- 成交价必须是 `官方开盘价 · 来源 · 结算 16:20`；不能显示成盘中“现价成交”。
- 已确认未结算：`已确认 09:12 · 待 16:20 结算`；不显示成交价、不占用持仓。
- 延迟行情：`延迟 3 分钟` + 来源 + “不用于纸面成交”。
- 过期数据：琥珀色点 + `16:10 后未入库`；不能继续显示为“最新”。
- 示例数据：水印 + 顶部横幅 + 所有数字带“示例”语义；不能与真实混排。
- 相对时间（“5 分钟前”）随渲染变化，服务端渲染需 `suppressHydrationWarning` 或客户端计算；避免 hydration 不一致。
- 来源层级写全（`交易所公告`、`巨潮`、`财联社`），不截成 2 字符；空间不足换行或收进 `来源：巨潮 · 交易所` tooltip，但不能只剩首字。
- 内部枚举一律映射中文（`fact` → `事实`、`inference` → `推断`、`limit_up` → `涨停`）；未知枚举显示原文 + `未知类型`，不静默空白。
- 证据分给完整刻度：`62/100 · 证据一般`，低分照样展示并说明“为什么不建议”；不能把低分过滤成“待分析”。

### 7.3 颜色与可访问性

- 红涨绿跌；同时用 `+/-`、箭头、文字（“涨/跌”），不依赖颜色。
- 颜色语义分工固定：

  | 语义 | 用法 | 禁止 |
  |---|---|---|
  | 红 `--up` | 上涨、盈利、正超额 | 成功、强信号、利好情绪、危险、分类系列 |
  | 绿 `--down` | 下跌、亏损、负超额 | 完成、通过、利空情绪、分类系列 |
  | 砚青 `--accent` | 品牌、主按钮、成功/完成 | 涨跌 |
  | 琥珀 `--warn` | 延迟、待确认、样本不足 | 涨跌 |
  | 深朱 `--critical` | 拦截、失败、kill switch（配图标+文案） | 涨跌、普通警告 |

- 情绪、信号强度、行业分类改用蓝/橙/紫等分类色；情绪发散用蓝↔橙 + 中性灰中点。
- 色盲模拟：红/绿在 deuteranopia/protanopia 下仍需可区分；必要时用蓝/橙作为图表分类色，不用红绿区分系列。
- 文本永远用文本色，不用系列色；系列色只给图形/点/线。
- 状态色（好/警告/严重/危急）保留，不用于“系列 4”。
- 图表 ≥2 系列必须有图例；≤4 系列可加直接标签；单系列标题即图例。
- 图表提供“表格视图”切换；屏幕阅读器可读摘要。
- 不使用双轴；不截断 y 轴误导；基线从 0 开始（除非明确标注并说明理由）。

### 7.4 图表规范

| 场景 | 形式 | 注意 |
|---|---|---|
| 市场温度 | 3 个指标 + 涨跌家数条 | 不画复杂仪表盘 |
| 净值 vs 基准 | 折线（≤3 条） | 单轴；图例；直接标签；表格视图 |
| 影子 vs 实际 | 折线（2 条） | 分类色 + 实线/虚线；图例写全；不合并成一条 |
| 回撤 | 面积/折线（单系列） | 从 0 向下；标注最大回撤点 |
| 行业暴露 | 横向条形（单系列） | 按权重排序；显示上限线 |
| 执行率 | 条形 + 计数 | 样本不足只显示计数；不画百分比结论 |
| 证据分校准 | 校准曲线/分组柱 | 样本不足时显示“样本不足”而不是硬画 |
| 决策质量 | 2×2 计数矩阵 | 文字 + 数量；不用散点堆 |
| 任务进度 | 进度条 + 状态文本 | 不用循环动画作为唯一状态 |

- 移动端图表最小高度 160px；标签不旋转 90°；必要时刻度减少。
- 所有图表有 `aria-label`/文字摘要；颜色不是唯一编码。

**现有图表迁移清单：**

| 现有图表 | 问题 | 迁移要求 |
|---|---|---|
| `AnalysisOverview` 情绪温度 | 红=利好、绿=利空，与 A 股红涨绿跌冲突 | 改蓝↔橙发散；补刻度含义与文字摘要 |
| `SentimentChart` | 色义冲突；无数据表 | 同上；补 `<table>` 视图与 `aria-label` |
| `BacktestPanel` 回测曲线 | 多系列无图例/无表格；可能双轴 | 单轴、≤3 条、图例 + 直接标签；补表格 |
| 行业暴露条 | 无上限线语义 | 显示上限线 + 超限标注；单系列单色 |
| 净值/回撤 | 需确认坐标起点 | 回撤从 0 向下；净值不截断；标注最大回撤点 |
| 任务进度 | 循环动画可能作为唯一状态 | 进度条 + 文本状态 + `aria-live` |

## 8. 交互与状态设计

### 8.1 渐进披露四级

| 层级 | 内容 | 默认 |
|---|---|---|
| L0 结论 | 今天要不要动、这张卡什么立场、最大亏损 | 首屏可见 |
| L1 理由 | 3 条关键证据 + 1 条反证 | 一级展开 |
| L2 证据 | 全部证据、来源、时间、快照 | 抽屉/详情页 |
| L3 原始 | 数据表、规则版本、计算明细、日志 | 进阶抽屉 |

- 任何一级都不能把“反证/最大亏损/数据质量”藏到 L3。
- 展开状态不强制持久化；同一页面内保持。

### 8.2 决策流程

```
今日/列表 → 决策卡详情 → 纸面委托票 → 确认 → 待收盘确认 → 16:20 结算
```

- 最多 3 次点击到“确认”；不超过 3 层弹层。
- 列表页不能直接确认；必须经过详情页的风险信封。
- 主按钮只有一个；次操作“再想想/不操作”不抢视觉。
- 确认前必须显示：买什么、多少、按什么价结算、最多亏多少、费用、09:15 截止、16:20 结算。
- 确认后显示“已确认，待收盘确认”，不是“已成交”；09:15 前可撤单，之后不可撤。
- 结算结果在今日页与订单页同步；失败给原因码 + 人话 + 下一步。

### 8.3 默认不操作

- 没有触发/风控不通过/数据 fail：主按钮是“查看原因”或“不操作”，不是“强行买入”。
- “不操作”是合法结果，复盘会记录；不要用灰色小字羞辱用户。
- 不做“连续 N 天未操作”的催促；不做 FOMO 倒计时。

### 8.4 空态

| 类型 | 标题 | 副文案 | 操作 |
|---|---|---|---|
| 没机会 | 今天没有值得动的机会 | 市场状态/数据质量/触发条件不满足 | 看观察名单 / 了解规则 |
| 没运行 | 今天的数据还没准备好 | 定时任务未运行/未入库 | 去任务中心 / 手动运行 |
| 没数据 | 这个标的还没有入库 | 行情/公告未抓取 | 发起深挖 / 返回自选 |
| 没持仓 | 还没有纸面持仓 | 虚拟资金还在现金 | 看决策卡 / 先模拟一笔 |
| 待结算 | 已确认，等待收盘 | 16:20 用官方开盘价结算 | 查看委托 / 09:15 前撤单 |
| 没复盘 | 还没有复盘 | 收盘后自动生成 | 手动运行 / 看今日 |
| 没权限/登录 | 需要登录 | 会话过期 | 去登录 |

- **空态 ≠ 错误态**：空态是“本来就没有”，错误是“该有的没算出来”。服务端异常不能返回空快照伪装成“还没有数据”。
- 空态不使用插画堆满屏；一个图标 + 一句原因 + 一个主操作即可。
- 错误态不显示堆栈/JSON；技术细节进“详情”。

### 8.5 错误态

三段式：

1. **发生了什么**：`行情源没有更新，今天的净值没有计算。`
2. **为什么**：`15:05 后未收到收盘数据；可能是源限流。`
3. **怎么办**：`重新检查` / `查看数据状态` / `稍后自动重试`。

- 不写“未知错误”“操作失败”单独一句。
- 可重试的操作给重试按钮；不可重试给替代路径。
- 资金/委托相关错误必须说明“是否已成交/是否扣款”，不能只说失败。
- **缺价与账本不平要分开说**：
  - `MISSING_PRICE`：`招商银行今天没有官方收盘价，这只股票的估值用了上一次价格；新买入已暂停，其他持仓不受影响。`
  - `LEDGER_MISMATCH`：`账本没有对上：现金与实际差 ¥1.00。已暂停新委托；请到数据健康页查看差异。`
- **静默刷新失败必须可见**：自动刷新失败时保留旧数据，但在区块顶部显示 `上次成功 15:05 · 本次刷新失败 · 重试`；不能一声不吭地继续展示旧值。
- 错误分区影响：只坏一个源时，坏块显示错误态，其余块正常，不用整页错误页。

### 8.6 加载态

- 骨架屏匹配最终布局，避免布局跳动。
- 超过 300ms 才显示加载；超过 5 秒显示“仍在处理 + 可以离开页面”。
- 不用全屏 spinner 遮住已有数据；局部加载。
- 任务型操作显示步骤（抓取→计算→生成），但不伪造进度百分比。

### 8.7 确认与撤销

- 纸面委托、重置实验、删除自选、解除 kill switch：必须确认，写清后果。
- 纸面委托确认即冻结现金/股数；09:15 后不可撤单，撤单窗口在按钮旁写明。
- 非资金操作（删除笔记、忽略卡片）可撤销 5 秒；资金操作不可“撤销”，只能反向委托/冲正。
- 重置实验需先导出备份；旧账户转只读，新开 `-v2` 并重新计时，确认文案写明「历史不会删，但不再计入新实验」。
- 破坏性按钮不用红色大按钮作为默认焦点；默认焦点在“取消”。

### 8.8 键盘与焦点

- Tab 顺序符合视觉顺序；焦点环 2px + 2px offset，深浅色都可见。
- 抽屉/弹层打开时焦点移入，关闭后回到触发按钮；Esc 关闭。
- 卡片可 Tab 到主操作；不把整张卡做成一个巨大的 tabindex。
- 快捷键：`/` 聚焦搜索（桌面），`g t` 今日，`g d` 决策；可在帮助中查看；不强制。

## 9. 新手引导与文案

### 9.1 首次使用（不阻塞）

在“今日”页顶部放一张可关闭的引导卡，4 步：

1. **这不是真钱，也不是随便造的数。** 虚拟资金，真实行情；你在 09:15 前确认，当天 16:20 按官方开盘价结算后，才算成交。不会接券商。
2. **先有一个候选池。** 系统从池子里挑 3–5 只写决策卡；每只都能点“为什么出现这只”。
3. **看懂一张卡。** 证据分、触发条件、最多亏多少、什么情况认错；这些都写在同一张卡上。
4. **分清两件事。** “系统判断”是系统自己按规则执行的结果，“我的执行”是你确认的纸面操作；复盘会分开算。

- 可“跳过”，设置里可重看。
- 不用全屏轮播；不强制点 5 步。
- 首次没有数据时，引导卡与空态合并，不叠加两层。

### 9.2 词汇表（16 个核心词）

| 词 | 人话解释 |
|---|---|
| 决策卡 | 一张写清“买什么、为什么、什么条件动手、什么条件认错”的研究结论 |
| 证据分 | 0–100 分，按固定规则把证据加总；不是上涨概率，也不预测涨跌 |
| 触发 | 满足什么条件才考虑动手 |
| 证伪 | 什么情况说明判断错了，应该退出/复核 |
| 待收盘确认 | 你已经确认，但 16:20 前还没有官方开盘价；不算成交、不计持仓 |
| 影子组合 | 系统按同一规则自己执行的账本，用来和你的实际执行做对照 |
| 执行率 | 触发的卡里，你实际确认的比例；不评价对错，只记录纪律 |
| 对账 | 用成交和流水重算现金、持仓、净值，看是否和账本一致 |
| 最大回撤 | 从最高点跌下来的最大幅度 |
| 超额 | 扣费后比基准多赚/少亏的部分 |
| 基准 | 用来比较的参照，如沪深300全收益 |
| 换手 | 一段时间内买卖的频繁程度 |
| 滑点 | 实际成交价和预期价的差 |
| T+1 | 今天买的股票，明天才能卖 |
| 涨跌停 | 一天最多涨/跌到的价格上限/下限 |
| 交易单元 | 一手；A 股通常是 100 股，科创板 200 股起 |

- 术语第一次出现用 `TermHint`；点击打开词汇表；不要求用户离开当前页。
- 不用“Alpha/Beta/Sharpe”作为主标签；中文优先，英文放括号/进阶。

### 9.3 文案语气

| 场景 | 不要写 | 改写 |
|---|---|---|
| 证据分 | 置信度中等 | 证据分 62/100：证据一般，先观察 |
| 回撤 | 回撤 8.2% | 从最高点跌了 8.2%，接近 10% 暂停线 |
| 缺失 | 暂无数据 | 缺少今日收盘价，所以没有计算市值 |
| 风控 | 风险超限 | 再买会让白酒行业到 43%，超过 40% 上限，所以没执行 |
| 触发 | 信号触发 | 招商银行已到 35.20，满足开盘条件；还需要你确认 |
| 待结算 | 已成交 | 已确认，待收盘确认；16:20 用官方开盘价结算 |
| 未触发 | 操作失败 | 今天开盘价 35.80，高于条件价 35.20，所以没有成交；卡已作废 |
| 风险缺口 | 操作失败 | 结算价 36.50 高于确认价，按实际成交算会超过单笔上限，所以没有成交 |
| 缺价 | 操作失败 | 招商银行今天没有官方收盘价；这只停用，其他持仓不受影响 |
| 空态 | 暂无内容 | 今天没有值得动的机会；系统建议不动 |

- 用“你”，不用“用户”；主动语态；一句话只做一件事。
- 不承诺收益，不制造紧迫感，不用“必看/重大/爆发”。
- 免责声明固定但不挡路：`虚拟资金 · 不构成投资建议`。

## 10. 响应式与移动端

### 10.1 断点

| 断点 | 宽度 | 布局 |
|---|---|---|
| 手机 | < 640px | 单列；底栏 5 项；粘性操作条 |
| 平板 | 640–1023px | 单列/两列；底栏 5 项 + 抽屉；不显示固定侧栏 |
| 桌面 | ≥ 1024px | 侧栏 + 主内容 + 上下文栏；隐藏底栏 |
| 宽屏 | ≥ 1440px | 主内容不无限拉宽；最大 1120–1200px |

- **导航形态只有一个切换点（1024px）**：`<1024` 用底栏 + 抽屉，`≥1024` 用固定侧栏。现有“768px 起出侧栏、底栏到 lg 才隐藏”会造成 768–1023 双导航，必须修复。
- 底栏与侧栏互斥由同一个 `useIsDesktop`（`min-width:1024px` 媒体查询）驱动，不用两套独立断点判断。

### 10.2 移动端规则

- 单手可达：主操作在底部安全区上方；不在右上角放唯一入口。
- 触控目标 ≥ 44×44px；相邻按钮间距 ≥ 8px。
- 表格转卡片；关键列（盈亏、风险、可用）必须在首屏卡片内。
- 图表高度 160–220px；横轴标签不旋转；可横向滑动时给渐隐提示。
- 底部导航不被 iOS 安全区遮挡；弹层不覆盖底栏主操作。
- 移动端粘性条必须带状态：`待触发 / 已触发（09:15 截止）/ 已确认，待收盘确认（16:20 结算）/ 已成交`；确认后按钮位显示结算时点，不显示“已成交”。
- 320px 宽度不横向滚动；长代码/数字可换行/缩略。
- **不依赖 hover**：消息操作（复制/分享/编辑/重试）、持仓行操作等触屏必须常显或通过“⋯”菜单访问；桌面可 hover 渐显，但键盘聚焦时同样出现。

### 10.3 桌面增强

- 侧栏 + 主内容 + 上下文栏；上下文栏放“今日待办/数据状态/相关卡”，不重复主内容。
- 决策列表可用左右分栏：列表 + 选中卡详情；移动端改为详情页。
- 支持键盘导航与命令面板；不牺牲移动端。
- 悬浮提示只作补充，不承载唯一信息。

## 11. 可访问性

### 11.1 标准

- 目标 WCAG 2.2 AA。
- 文本对比度 ≥ 4.5:1；大字/图标 ≥ 3:1；焦点指示 ≥ 3:1。
- 所有功能可键盘完成；无键盘陷阱；跳过主内容链接保留。
- 屏幕阅读器：语义标题层级、表格 `<th scope>`、图表文字摘要、状态 `aria-live`。
- 200% 缩放不丢内容；320px 宽不横向滚动（数据表可在区域内滚动，但核心信息不能）。
- `prefers-reduced-motion: reduce` 时关闭非必要动画/平滑滚动。
- 表单错误与字段关联；不用 placeholder 代替 label。

### 11.2 具体检查

- 立场/证据分/风险：颜色 + 图标 + 文本。
- 图表：`role="img"` + `aria-label` 摘要；提供表格视图；不把图例做成唯一说明。
- 弹层/抽屉：焦点管理、Esc、`aria-modal`、标题关联。
- 动态状态：提交中/成功/失败用 `aria-live="polite"`；错误用 `assertive`（谨慎）。
- 结算状态变化（已确认 → 已成交 / 未触发 / 缺价）用 `aria-live="polite"` 播报完整句子；金额与股数同时给文本，不只靠颜色/图表。
- 触控：44px；移动底栏文字不小于 11px 但图标 22px；关键操作不小于 14px。现有 `h-7`/`h-8`/`size-6` 图标按钮不改高度就把热区扩到 44px。
- 筛选/分段控件：选中态用 `aria-pressed`（或 `role="tab"` + `aria-selected`），不能只靠背景色。
- 可排序表头：`aria-sort="ascending|descending|none"`；点击区是 `<button>`，不是整格 `onClick`。
- 标题层级：每页唯一 `<h1>`，按 h1→h2→h3 不跳级；顶栏文字不承担标题语义。
- 登录等关键表单：密码可见切换不能 `tabIndex={-1}`；错误提示与字段 `aria-describedby` 关联。
- 语言：`<html lang="zh-CN">`；英文缩写首次出现给中文。
- 动效：不闪烁；不自动播放；不做数字滚动动画承载信息。

## 12. 性能与工程质量

- 今日页 LCP < 2.5s（4G/中端手机），CLS < 0.1，INP < 200ms。

## 13. 迁移与实施顺序

顺序服从验证优先：先把数据、账本、决策卡和四张最小页面跑起来，再迁移研究与进阶功能。与模拟盘规格 §19 的阶段 A–G 一一对齐。

### Step 0 — 契约冻结与基线（1 周）

- 冻结 API 字段与枚举：卡状态、委托状态、原因码、`price_basis`、`settlement`；mock 必须与真实 schema 同名同枚举，禁止 UI 先造字段后返工。
- 设计 token、字体、间距、焦点、暗色；用对比度工具验证。
- `PageHeader`、`StatusPill`、`MetricTile`、`EmptyState`、`ErrorState`、`TermHint`、`GlossarySheet`、`SettlementStatus`、`ReconciliationStrip`。
- 统一 `AppShell`/`CockpitShell` 为一个外壳；保留现有 props 兼容。
- 交互基线清理：空态/错误态分离、每页唯一 h1、筛选 `aria-pressed`、表头 `aria-sort`、44px 触控、密码可见按钮键盘可达、来源不截断、枚举中文映射。

### Step 1 — 最小验证 UI（2–3 周，依赖模拟盘阶段 A–C）

- 今日页最小版：一句话 + 市场温度 + 我的持仓 + 待办；不加载研究图表。
- 模拟盘列表/详情/纸面委托票/委托状态；接真实账本接口。
- 持仓页只读版：总持仓/可用/冻结、待收盘确认、对账状态。
- 数据健康页最小块：入库时间、缺价、对账。
- 新手引导与词汇表。

### Step 2 — 复盘与双轨（1–2 周，依赖阶段 D）

- 复盘页：事实摘要、系统判断/我的执行/执行率三栏、影子 vs 实际两条线。
- 执行率与偏离原因；样本不足只显示计数。
- 数据健康页补备份状态与恢复演练记录。

### Step 3 — 信息架构切换（1 周）

- `lib/nav.ts` 改为 5 项 + 研究二级；新增 `/paper` 路由。
- 移动底栏 5 项；`/desk` 重定向到 `/today?session=intraday`。
- 导航断点收敛到 1024px，消除 768–1023px 双导航；匿名分享页改 bare layout。
- 旧 IA 与导航变更放在 `paper_cockpit_v2` feature flag 后；flag 关闭时旧入口完全不变。
- 同步更新 `public/manifest.webmanifest` 的 `start_url`/shortcuts、Electron 托盘菜单与深链协议；旧路径逐条 redirect 并加路由测试，避免 PWA/桌面入口落到 404。
- 颜色语义清理：情绪/信号不再用红绿；成功/危险改图标 + 文案。

### Step 4 — 研究 + 进阶（2 周，L1 运行后再做）

- 研究二级导航；自选/个股/行业/新闻/助手统一视觉。
- `/analysis`、`/analytics/value` 收进进阶工具。
- 任务中心简化；主题迁移、14 天引导、命令面板、旧图表迁移。

### Step 5 — 打磨与验收（1 周）

- 可访问性、移动端、性能、空态/错误态全量走查。
- 可用性测试与修复。

> 每阶段独立可发布。研究/进阶/主题/14 天引导/命令面板/图表迁移全部后置到 L1 观察期开始之后，不阻塞验证；旧页面在 flag 关闭时可原样保留。

## 14. 验收标准

### 14.1 可用性测试（5 名新手）

任务与通过标准：

1. **今天要不要动？** 15 秒内说出结论与原因；5/5 完成。
2. **这张卡为什么建议买？** 60 秒内说出至少 2 条证据 + 1 条反证；4/5 正确。
3. **确认一笔纸面委托后，什么时候成交、最多亏多少？** 90 秒内完成确认，并说出“16:20 按官方开盘价结算”与最大亏损；5/5 完成，4/5 数值正确。
4. **这笔为什么没成交？** 30 秒内找到原因；5/5 完成。
5. **这个月跑赢基准了吗？样本够吗？** 60 秒内找到超额与样本提示；4/5 正确。
6. **系统判断和我自己的执行差在哪？** 60 秒内指出影子/实际两条线、执行率和一个偏离原因；4/5 正确。

其他：

- SUS ≥ 80；或任务完成率 ≥ 90% 且关键理解题 ≥ 80%。
- 没有“看不懂但不敢问”的阻塞点；用户能说出下一步。

### 14.2 设计走查

- [ ] 首屏只有一个主任务；最多 3 个主操作。
- [ ] 结论、风险、反证、数据质量在 L0/L1 可见。
- [ ] 所有数字有单位/口径/时间；缺失显示“— + 原因”。
- [ ] 所有来源可点/可追溯；延迟/示例/过期状态显性。
- [ ] 红涨绿跌 + 箭头/符号；色盲模拟可区分。
- [ ] 移动端 320px 无横向滚动；关键信息不被隐藏。
- [ ] 键盘可完成主要流程；焦点可见；弹层焦点回收。
- [ ] 图表有文字摘要/表格视图；无双轴。
- [ ] 空态/错误态有原因 + 下一步，且二者不混用；自动刷新失败可见。
- [ ] 新手模式隐藏进阶指标，但不隐藏风险。
- [ ] 持仓页显示价格覆盖、排除市值、收益率分母。
- [ ] 颜色语义无冲突：红绿不出现在情绪/信号/分类图；成功与危险都有图标 + 文案。
- [ ] 来源层级完整、内部枚举已中文化、低分信号完整展示。
- [ ] 768–1023px 不出现侧栏 + 底栏双导航。
- [ ] 每页唯一 h1；筛选有 `aria-pressed`；表头有 `aria-sort`；看不见 hover 也能完成操作。
- [ ] 设置默认只有基础项；高级折叠；不出现真实下单入口。
- [ ] 列表页没有“纸面买入”；确认入口只在详情页，且确认前可见结算时点、09:15 截止、最大亏损。
- [ ] 确认后状态是“已确认，待收盘确认”，不是“已成交”；16:20 前持仓/成交不出现该笔。
- [ ] 复盘页同时显示系统判断与我的执行，且不合并成一条净值线。
- [ ] 对账状态与 kill switch 状态可见；缺价只停该标的，不会误报“账户已冻结”。
- [ ] 匿名分享只含问题 + AI 摘要 + 来源标题/链接；预览脱敏；过期/撤回状态可见。

### 14.3 技术验收

- [ ] Lighthouse Performance ≥ 90（移动，本地/预发）。
- [ ] Accessibility ≥ 95；无 critical axe 问题。
- [ ] CLS < 0.1；LCP < 2.5s；INP < 200ms。
- [ ] 200% 缩放、深浅色、减少动画通过。
- [ ] 旧路由不 404；深链可用；`/desk` 重定向正确。
- [ ] 无示例数据混入真实页面；水印正确。
- [ ] 320 / 768 / 1024 / 1440 四个宽度截图走查通过；无横向滚动、无双导航。

## 15. 风险与取舍

| 风险 | 表现 | 缓解 |
|---|---|---|
| 过度简化 | 新手看不到风险/反证 | 风险信封 + L1 反证；简化只藏“进阶指标” |
| 信息过载 | 首屏又变成仪表盘 | 一个主任务 + 三块 + 待办；其余展开 |
| 术语替换不彻底 | 一半人话一半黑话 | 词汇表 + 文案 lint + 首次出现解释 |
| 品牌色与涨跌色冲突 | 用户误读红绿 | 品牌砚青；红绿只做语义；图标辅助 |
| 旧页面拖累 | 导航降级后仍被搜到 | 保留路由但加“进阶”标识；不在主导航 |
| 移动端底栏拥挤 | 5 项仍难点 | 44px 触控；文字 11px 但图标 22px；系统入口移出 |
| 数据延迟误导 | 用户把延迟当实时 | 每个数据块标时间/延迟；延迟行情不用于成交 |
| 把“待收盘确认”当已成交 | 误以为持仓/盈亏已发生 | 状态色 + 沙漏 + 明确文案；未结算不计持仓/成交；复盘区分 |
| 影子与实际混算 | 归因错误，高估方法有效性 | 分账、双线、三栏；禁止合并净值；执行率单列 |
| 分享越界 | 决策卡/持仓被公开 | 字段白名单 + 脱敏预览 + 7 天过期 + 可撤回 |
| 契约后改字段 | UI 二次返工、mock 与真实不一致 | Step 0 冻结 API/枚举；mock 与真实 schema 同名 |
| 可用性测试样本小 | 结论不稳 | 5 人定性 + 后续行为数据；不宣称统计显著 |

## 16. 待确认决策

已定：主导航 5 项为 **今日 / 模拟盘 / 持仓 / 复盘 / 研究**，移动底栏同序；任务/数据/设置走系统入口。

1. **品牌色**：恢复“雾灰绿 + 砚青”，还是保留现有蓝色？建议恢复，但先做对比度验证。
2. **`/desk` 是否完全并入 `/today`**：建议并入，保留重定向；盘中作为今日页的一个 session。
3. **持仓默认视图**：模拟盘 vs 真实记录；建议模拟盘（验证期）。
4. **`/analysis` 是否保留完整页**：建议保留但在“研究 → 进阶工具”，不在一级导航。
5. **新手模式默认时长**：14 天 vs 永久默认；建议 L1 运行后再加引导，先不阻塞验证。
6. **是否引入命令面板**：桌面加分项，移动不需要；可作为 P1。
7. **是否保留研究助手的独立全屏聊天**：建议保留，但从决策卡/个股带入上下文；不作为主入口。
8. **影子组合是否默认开启**：建议默认开启；实验开始前可关闭，开始后锁定。
9. **匿名分享是否允许带纸面结果**：建议禁止，只允许问题 + 摘要 + 来源标题/链接。
10. **初始虚拟资金**：固定 20 万还是三档？建议固定 20 万，避免实验间不可比。
11. **股票池边界**：建议允许手动加入候选池，但不能手动生成决策卡；卡仍由规则引擎产出。
12. **风控上限是否可改**：建议 L1 只读；要改必须新建实验并锁新策略版本。
13. **全收益基准的免费稳定来源与许可**：待 M-1 spike 确认（如 H00300 / H00905）。

## 18. 一句话验收

**新手不展开任何抽屉，也能知道今天要不要动、为什么、最多亏多少、什么时候成交，并分清“系统判断”和“我的执行”；想追问时，两步之内能看到来源、证据和计算口径。**
